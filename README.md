# Data Engineering Practical Journal & Manual

Welcome to the **Data Engineering** repository. This repository contains the complete practical journal, lab manual, setup guides, and exercise documentation covering core data engineering concepts and lab tasks from Practical 1 to 10.

---

## 📁 Repository Contents

* **`Data_Engineering_Practical_Journal_Vedanti_Sawant_1_to_10.ipynb`**: Complete Jupyter Notebook containing hands-on implementations, data processing pipelines, queries, and execution outputs for Practicals 1 to 10.
* **`Main_Data_Engineering_Practical_Manual_1_to_10_FINALvedanti_CodeBoxes.docx`**: The primary lab manual containing step-by-step instructions, practical setups, code boxes, and documented output reports.
